# The World in One Day — Thursday 19 November 2026

A 1024x1024 front-page poster drawn entirely in code (`main.ts`, Node
standard library only: a hand-written 5x7 bitmap font, vector pictograms
and a small PNG encoder). It sums up Thursday 19 November 2026 in
38 stories: a hero row with the three biggest stories of the day and a
dense index of 35 more, across every region and beat.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png` (1024x1024 PNG, well under the 1 MiB limit).
Deterministic: repeated runs produce identical bytes.
